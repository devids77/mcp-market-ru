Как добавить MCP Market в Claude Desktop

3 шага — и ваш AI-агент получит доступ к каталогу из 3 395 компаний с рейтингами и проектами.

1
Откройте конфиг Claude Desktop.
macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
Windows: %APPDATA%\Claude\claude_desktop_config.json
2
Вставьте блок mcpServers: 
{
  "mcpServers": {
    "mcp-market": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://mcp-market.ru/mcp/"]
    }
  }
}
3
Перезапустите Claude Desktop.
Спросите Claude: «Найди через mcp-market 3 лучших компании по установке заборов в Краснодаре» — получите живые данные с рейтингами.
