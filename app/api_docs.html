MCP для AI-агентов

Подключите к Claude, GPT или другому AI-агенту через Model Context Protocol

21 инструмент через MCP streamable-http transport:

search_companies, search_projects, get_company, get_project, get_categories, get_regions, get_stats, compare_companies, calculate_cost, request_quote, market_analytics, find_best_companies, price_comparison, company_portfolio, market_report, review_analysis, contractor_recommendation, project_estimator, trend_analyzer, company_deep_profile, region_comparison

Endpoint

https://mcp-market.ru/mcp/

Подключение из Claude Desktop

{"mcpServers": {"mcp-market-russia": {"url": "https://mcp-market.ru/mcp/"}}}

Прямой JSON-RPC (curl)

1. initialize — получить session ID:

curl -i -X POST https://mcp-market.ru/mcp/ \ -H "Content-Type: application/json" \ -H "Accept: application/json, text/event-stream" \ -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"my-agent","version":"1.0"}}}' # ответ содержит header: mcp-session-id: <sid>

2. notifications/initialized — подтвердить готовность:

curl -X POST https://mcp-market.ru/mcp/ \ -H "Content-Type: application/json" \ -H "Accept: application/json, text/event-stream" \ -H "Mcp-Session-Id: <sid>" \ -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

3. tools/list — получить список 21 инструмента:

curl -X POST https://mcp-market.ru/mcp/ \ -H "Content-Type: application/json" \ -H "Accept: application/json, text/event-stream" \ -H "Mcp-Session-Id: <sid>" \ -d '{"jsonrpc":"2.0","id":2,"method":"tools/list"}'

4. tools/call — вызвать инструмент (пример: поиск компаний):

curl -X POST https://mcp-market.ru/mcp/ \ -H "Content-Type: application/json" \ -H "Accept: application/json, text/event-stream" \ -H "Mcp-Session-Id: <sid>" \ -d '{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"search_companies","arguments":{"query":"забор","limit":3}}}'
Важно: ответы возвращаются как Server-Sent Events (text/event-stream). Парсите строку, начинающуюся с data: , как JSON. Header Mcp-Session-Id обязателен для всех запросов после initialize.
