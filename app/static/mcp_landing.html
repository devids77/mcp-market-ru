MCP endpoint для AI-агентов v3.1.1

Вы открыли https://mcp-market.ru/mcp/ в браузере. Это технический endpoint MCP-протокола для AI-агентов — через него подключаются Claude, Cursor, Windsurf и другие совместимые клиенты. Ниже — как подключить.

💡 Если вы AI-агент и ожидали JSON-RPC ответ — отправьте запрос с заголовком Accept: application/json, text/event-stream.

1. Claude Desktop

Откройте файл конфигурации и добавьте блок mcp-market. На macOS: ~/Library/Application Support/Claude/claude_desktop_config.json. На Windows: %APPDATA%\Claude\claude_desktop_config.json.

{
  "mcpServers": {
    "mcp-market": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://mcp-market.ru/mcp/"
      ]
    }
  }
}

После сохранения перезапустите Claude Desktop. В списке инструментов появятся search_companies, calculate_cost, market_analytics и ещё 18 тулзов.

2. Cursor / Windsurf

В настройках MCP добавьте URL сервера:

https://mcp-market.ru/mcp/

Транспорт: streamable-http. Авторизация не требуется.

3. curl (проверка)

Инициализация сессии:

curl -N https://mcp-market.ru/mcp/ \
 -H "Content-Type: application/json" \
 -H "Accept: application/json, text/event-stream" \
 -d '{"jsonrpc":"2.0","id":1,
      "method":"initialize",
      "params":{"protocolVersion":"2024-11-05",
      "capabilities":{},
      "clientInfo":{"name":"curl","version":"1"}}}'
